# Static Portfolio (GitHub Pages Ready)

Simple, modern one-page portfolio site.

## Run locally

Open `index.html` in your browser.

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main** (or your current branch), folder: **/root**
4. Save and wait for deployment.
5. Your live link will look like:
   - `https://<username>.github.io/<repo-name>/`

## Personalization

- Update name/text in `index.html`
- Update social/profile links
- Add your real project details
